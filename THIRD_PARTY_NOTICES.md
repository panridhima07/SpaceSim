## OpenRocket and ThrustCurve data

- ThrustCurve.org: scripts/fetch-data.mjs queries the public API (21 listed Estes, AeroTech, Cesaroni motors) and writes src/ork/motorData.json, which IS committed and shipped in the app bundle. docs/PLAN.md describes the source as "public data". No ThrustCurve terms or attribution text is recorded in the repo; confirm their terms of use and consider crediting ThrustCurve.org and the certification bodies in the app.
- OpenRocket example .ork files: licensed GPL. They are downloaded at dev time into fixtures/external/, which is git-ignored (.gitignore) and not shipped; tests that need them skip if absent. The folder was not present in the checkout inspected.
- OpenRocket source: docs/PLAN.md says it is used as a reference for the file format and Barrowman details only, with no code copied, so the project is not bound by the GPL. This claim is unverified here (no code diff against OpenRocket was done).
- No other large motor tables were found in public/ or src/ beyond motorData.json.
